# A2A Agent-to-Agent Tutorial

> **Value:** Medium &nbsp;|&nbsp; **Implementability:** Moderate

## What this is
Build a minimal Agent2Agent system: a Research agent + Writer agent discovered via agent-cards and chained by an orchestrator.

## Why it's worth building
A technically sound, ~20-minute build that teaches multi-agent mechanics (agent-card discovery, JSON-RPC chaining) and the real distinction between A2A (sideways teammates) and MCP (downward tools). More learning value than daily utility.

## What to build (the gist)
- The agent-card at /.well-known/agent-card.json is the discovery trick.
- Two independent agent servers + a thin orchestrator that only knows URLs.
- Good mental model for your own subagent orchestration; A2A itself is still early.

## What's here
A runnable, dependency-light A2A demo (Python stdlib only -- no FastAPI, no
a2a-sdk, no API key required to run):

- `agent_card.py` -- `build_card(...)` builds a card dict; `AGENT_CARD_PATH`
  is the well-known path; **`stub_llm`** is the default offline LLM, and
  `make_groq_llm()` / `make_anthropic_llm()` are the real-LLM plug points.
- `a2a_server.py` -- shared stdlib `http.server` shell. Serves a card at
  `/.well-known/agent-card.json` (GET) and a JSON-RPC-flavoured
  `/message` (POST).
- `research_agent.py` -- summarizes a topic. `build_agent_card()` +
  pure `handle_message(topic, llm=stub_llm)`. Server on port 8001.
- `writer_agent.py` -- rewrites text simply. Same shape; port 8002.
- `orchestrator.py` -- no AI logic. `run(topic, research_url, writer_url,
  get_card=..., send_message=...)` discovers both cards and chains
  topic -> Research -> Writer. Transport is injectable for testing.
- `test_a2a.py` -- TDD tests (card construction, handler logic, orchestrator
  chaining), all in-process with the stub llm -- no sockets, no key.

## Usage

Run the tests (from the repo root, all offline):

    .venv\Scripts\python.exe -m pytest projects\a2a-agent-tutorial

Run the live demo -- start each agent in its own terminal:

    cd projects\a2a-agent-tutorial
    ..\..\.venv\Scripts\python.exe research_agent.py 8001
    ..\..\.venv\Scripts\python.exe writer_agent.py 8002

Then in a third terminal, run the orchestrator:

    ..\..\.venv\Scripts\python.exe orchestrator.py

Inspect a card directly:

    curl http://localhost:8001/.well-known/agent-card.json

### Plugging in a real LLM
Every agent calls an `llm(prompt) -> str`. The default is the offline
`stub_llm`. To use a real model, pass your own `llm` to `handle_message`
(or edit the agent's `main()`):

    from agent_card import make_groq_llm     # pip install groq; set GROQ_API_KEY
    handler = lambda t: research_agent.handle_message(t, llm=make_groq_llm())

`make_anthropic_llm()` (set `ANTHROPIC_API_KEY`) works the same way. Both are
inert until you install the dep + set the key.

## Effort
Contained coding exercise. The official tutorial uses the FastAPI/Groq + a2a-sdk
stack; this version trades the SDK for stdlib to stay dependency-light and
runnable with no key.
