# Frontend-Quality Skill Setup

> **Value:** Medium &nbsp;|&nbsp; **Implementability:** Easy

## What this is
Compose skills so Claude produces less generic 'AI-slop' UI and self-reviews via screenshots.

## Why it's worth building
The pain is real and the reusable technique — have Claude screenshot its own UI and self-review before showing you — genuinely lifts quality. Most of the source posts are third-party skill funnels, so vet each.

## What to build (the gist)
- Start from the frontend-design skill already in your environment.
- Add a screenshot -> self-review -> refine loop before output is shown to you.
- Vet any third-party skill before trusting it; ignore '$10k website in one command' hype.

## First steps
1. Skim the source posts' extracts in `exports/items/` for the exact text/claims.
2. Stand up the smallest useful version first (one file / one skill / one template).
3. Wire it into your existing Claude Code setup; iterate.

## Effort
Mostly composing existing skills + a screenshot-review loop.

## What's here
- `SETUP.md` — how to set up frontend quality in three layers: (1) lean on the official `frontend-design` skill for all aesthetics, (2) an honest rundown of the external pieces the source name-drops (21st.dev, Framer/Motion, "UI/UX" skills) with vetting caveats — the "one command" is a comment-funnel, and (3) the technique that actually matters.
- `screenshot-review.md` — a ready-to-use skill (`name: frontend-screenshot-review`) for the screenshot -> self-review -> refine loop: render the UI, screenshot it with Playwright, critique against design heuristics, fix in code, repeat, and only then show the user.

## Usage
1. Read `SETUP.md` once to understand the three layers.
2. Keep using the official `frontend-design` skill for aesthetics (it's already active in this environment).
3. For the external tools section, vet each piece yourself; install only what you read (Motion is the safe bet).
4. After Claude builds any non-trivial UI, run/paste `screenshot-review.md` so it self-reviews before showing you. One-time: `npm i -D playwright && npx playwright install chromium`.
