Before writing code, establish the contract for this work:

$ARGUMENTS

1. Restate the goal in one sentence.
2. Write an explicit, checkable **Definition of Done** — a bullet list of conditions
   that must ALL be true to call it finished.
3. For each condition, state how it will be verified (which command, test, or
   observable behavior proves it).
4. List unknowns and assumptions. If any of them would change the approach, ask now
   rather than guessing.
5. Then proceed, and don't stop until every definition-of-done item is verified.

Keep the Definition of Done visible and check items off as you complete them.
